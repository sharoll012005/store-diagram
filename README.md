# Sales Recorder

I turned my old paper sales log into a Python script.

## What it does
- Prompts for product, unit price and units, validates input.
- Stores each sale as a dict in a list.
- Asks if I want to register another sale and keeps adding while I answer yes.
- Prints a summary of all sales with totals.

## Why
No more lost notebooks. The script is versioned with git, so I can track changes and share it.

## Usage
Run python main.py, follow the prompts, and you’ll get a clear list of purchases and the grand total.
